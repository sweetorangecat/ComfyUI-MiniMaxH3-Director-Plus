# U24 文武双修与高显存 FHD 实施计划

目标：修复智能模式有音色时始终单采的清晰度限制，并提供独立、忠于 U24 接线的高显存 1080p 工作流。

设计：导演台沿用已有 U22 二采和完整首采音频保护，在依赖齐备且显存预算满足的 FHD 请求自动启用；显式环境变量 0 保留单采。U24 单独交付 T8 原生节点图，不把 U22 的 beta/Euler 冒充双时钟。保留 U24 的 LoRA、9 步基础调度取前 4 步、5 步独立精修、12/3 双时钟、HIGH 重新编码与最终 output 插槽；目标网格为 960×544 → 1920×1088 → 中心裁切 1080p，默认 5 秒固定种子便于对照。

替代方案：只锐化不能补充采样细节；将全部 U24 LoRA 直接堆入现有单采会丢失分阶段强度和采样契约。选择自动二采修复 + 独立完整 U24 工作流。

- [ ] 修改并复现 smart/director 回归测试，再调整 FHD 自动规则与回退提示。
- [ ] 基于用户 U24 JSON 生成去除演示素材/失效预览、注明来源的 FHD 工作流；验证双时钟、两套模型、HIGH 条件、输出槽与网格。
- [ ] 增加带固定版本、SHA256 校验的模型补齐工具；来源不明的电影 LoRA 明确保留缺失状态，不用同名假替代。
- [ ] 核查源视频帧；运行相关与完整测试；文档记录来源、实际能力与尚未 GPU 验证的边界。
