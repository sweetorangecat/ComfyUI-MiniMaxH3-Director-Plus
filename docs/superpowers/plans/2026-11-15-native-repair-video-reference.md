Goal: add a reviewed native video phase reference to the existing bounded repair, then retest the rejected office window and complete the 90-second scene. Completion requires actual media review; CPU checks alone do not certify motion, speech or full-film delivery. Shutdown follows completion, not an unsuccessful attempt.

Design: one optional `video_reference` on an existing repair, with `source_take`, native `source_steps`, `target_steps` and an immutable `review` receipt. Sources are current accepted earlier windows in the same project. Only genuinely unused source tail is eligible. A separate review records the actually observed pose and prop state. The source and target intervals must align to the native five-step codec group and have equal lengths. The reference is installed before sampling and protected by the original video mask; the rest of the declared repair remains free. Audio remains under the existing independent mask. No RGB insertion, temporal cuts, reused delivered frames, new UI, or changes to the short-video path.

Keep geometry validation and source provenance in `nodes/long_video_repair.py`. `long_video_av.py` handles the tensor copy, `long_video_store.py` checks the receipt before invalidation and take creation, and `long_video_runtime.py` reloads/verifies the exact source before preparation. `long_video_service.py` exposes the expert review action and fingerprints the new module. Existing source hashes and immutable take requests remain unchanged. Changed generation code must still trip the existing deployment guard; no silent rewrite of old project fingerprints.
