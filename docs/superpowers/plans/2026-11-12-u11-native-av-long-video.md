# U11 原生 AV 长视频实施计划

**Goal:** 将已实测的 Ref2VA / SelfLift global / clean AV 续窗方法接入同一个 U11，支持有限目标时长、停止、恢复、局部返修及原路径增强。

**Architecture:** 复用当前 U11 的实际 API 图和全部素材/模型/加速配置。统一输出节点在短片模式下调用原输出；长片模式下只启动磁盘项目协调器，由标准 ComfyUI 队列逐窗执行原图。原生窗口存盘并审查后才能增强和交接。规划、AV 张量、图编译、状态、运行节点、媒体装配各有独立模块。

**Tech Stack:** Python, ComfyUI 原生队列与 lazy 输入, Torch, safetensors, PyAV, 原 U11 SelfLift / VOSR2, JavaScript。

设计依据为源 checkout 的 `docs/U11-native-av-long-video-integration.md` 和 2026-11-12 的 30 秒返修回执。该工单已获用户授权；本计划不新增人工实施批准步骤。

- [x] 规划与正文：纯函数按任意有限总帧数规划真实共同 AV 端点、历史与安全尾；六段 Ref2VA 正文逐窗编译，完整对白不跨交接，尺度值不平移。测试 30/60/120 秒、舍入、短尾、边界冲突和推进。
- [x] AV 保护：从 clean AV 截取真实历史并生成两条 mask；支持指定视频 latent 范围返修、锁音频；验证保护区逐元素相等、开放区变化和实际 global 分支，禁止无 mask 降级。
- [x] 图与项目：保留当前 U11 配方与上传槽位，原生检查点不可变。生成/导出指纹分离，按真实父历史记录依赖；中断可恢复，目标增长保留有效前段，停止不再提交后续窗口。
- [x] 队列与媒体：逐窗标准队列执行、原生预览、内容审查、原 U11 增强；仅连续净新增区间装配，逐文件读取，精确累计音频采样索引、FPS、PTS和全解码检查。完成前保存检查点，失败保留诊断。
- [x] U11 入口：默认关闭的可选长视频配置，统一输出兼容旧参数；提供项目进度、原生审查、继续/停止和局部返修。更新原 U11 JSON/构建工具而不另造独立生产工作流。
- [x] 验证与交付：运行新模块与原短片回归、工作流结构检查；自审和独立审查后提交功能分支。分别记录代码、部署和 GPU 内容验证状态，60 秒及更长保留待实测标记。

验证运行时使用 `D:/ComfyUI_windows_portable-G313/python_embeded/python.exe`；源 checkout 现有 Comfy 测试桩仅用于隔离测试。原有四个用户修改及实验文件保持原位，不纳入功能提交。
