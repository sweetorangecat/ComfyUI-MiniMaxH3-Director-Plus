# 质量优先加速设计

## 目标

为 U11 导演台增加一个“质量优先加速”性能预设，在尽量保持稳定质量的前提下使用 SageAttention 加速。

## 行为契约

- 采样步数固定为 20 步，不使用 Turbo LoRA。
- 启用 SageAttention；不启用 EasyCache，避免细节变软或运动拖影。
- T2VA、I2VA、FL2VA、L2VA、REF2VA 和带音色参考的路由均可选择该预设。
- SageAttention 或对应优化节点不可用时，模型回退到原生模型，仍保持 20 步。
- 该预设通过现有性能下拉框暴露，不新增节点、不改变导演台布局。
- API 的性能预设枚举、路由白名单、中文说明和文档同步更新。

## 取舍

该预设的加速幅度低于 4 步 Turbo，但画质最接近稳定质量；它不需要下载额外模型。现有“极速4步”和“参考图加速”保留原有用途和行为。

## 验收

- 每个模式和音色参考路由都允许并正确解析该预设。
- 运行时契约为 20 步、Sage 开启、缓存关闭、Turbo LoRA 关闭。
- 加速节点失败时不降低步数、不残留 Turbo 采样状态。
- Python 全量测试、JS 语法检查和 Git 差异检查通过。
