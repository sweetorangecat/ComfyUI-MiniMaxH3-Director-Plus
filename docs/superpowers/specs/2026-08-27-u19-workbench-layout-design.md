# U19 工作台视觉升级设计

## 目标

参考 `U19-MiniMax-H3-Director导演台二采加速.json` 的工作台层次，把当前唯一的 U11 Director Plus 工作流整理成稳定的三列工作台：顶部标题与状态、左侧说明/能力、中间导演控制台、右侧预览与最终输出。

本次只改变工作流画布的视觉组织和输出选项，不改变 MiniMax H3 的模式自动路由、兼容性能预设、音色参考、二采、显存策略、色彩保护或 API 契约。

## 约束与不变项

- 继续只有一个 `MiniMaxH3DirectorPlus` 节点。
- 继续只有一个 `MiniMaxH3StreamingVideoCombine` 最终输出节点。
- 用户切换模式后仍由 Director Plus 自动选择模型、加速和二采链路，不要求手动连接节点。
- 不引入 U19 的旧 `MiniMaxH3Director`、`MiniMaxH3DirectorRefine`、手动 LoRA、手动调度器或重复输出链。
- Director DOM 保持固定宽度与固定高度，避免 ComfyUI 右侧边栏改变节点尺寸。
- 所有新增可见说明使用中文，且不在节点之间制造交叠。

## 画布布局

### 顶部

在画布上方放置一个大标题、版本/插件状态和简短的 API 提示，借鉴 U19 的标题层次但不复制其群号或外部宣传文字。

### 左列：能力与说明

左列分成两个垂直区域：

1. `快速设置`：保留现有 Settings 子图及其自动路由输入。
2. `使用说明与能力状态`：保留中文快速开始、提示词示例、模型说明和本机能力状态节点。

左列宽度固定，说明节点的边界按实际内容设置，不能覆盖中列。

### 中列：导演控制台

中列只放一个 Director Plus，使用 U19 的视觉重点：绿色/青绿色分组标题、显眼的导演控制台名称和连续的素材区。节点尺寸沿用当前 `1350 x 1510`，不因为右侧面板打开而缩窄。

### 右列：预览与输出

右列按从上到下排列：

1. 运行报告/状态预览。
2. 唯一的视频预览与输出节点。
3. 输出说明（最终尺寸、音频、编码格式）。

视频输出固定为 H.264/MP4。输出节点增加并显示两个独立选项：

- `保存首帧图片`，默认关闭；
- `保存尾帧图片`，默认关闭。

这两个选项只导出首帧/尾帧图片，不增加视频链、不改变视频帧数、不改变音频，也不参与 H3 采样。

## 颜色与视觉语言

- 模型/能力：蓝色系；
- 导演控制台：青绿色系；
- 预览/输出：灰蓝色系；
- 说明文本：低对比度深色背景，保证长文本可读。

颜色只用于分组识别，不使用大面积渐变、装饰性浮层或嵌套卡片。

## 数据流与 API

不新增 API 必填入参。工作流模板继续由 `build_api_template()` 生成；首帧/尾帧导出选项作为输出节点已有的布尔输入暴露，默认值为 `false`。

## 错误处理

- 结构校验必须拒绝重复节点 ID、断链和可见节点重叠。
- 生成器若找不到唯一输出节点或 Director Plus，应直接失败，不生成半成品工作流。
- 旧输出节点升级时按输入名称重映射，不能按旧槽位盲连；新增首尾帧选项必须保持默认关闭。

## 验证标准

- 生成的 U11 JSON 可被现有工作流校验器通过。
- 主画布无可见节点重叠，且三列分组边界不相交。
- 主画布恰好一个 Director Plus 和一个 StreamingVideoCombine。
- 输出节点同时包含 `save_first_frame` 与 `save_last_frame`，默认均为 `false`。
- 现有全量测试通过，工作区无 `git diff --check` 错误。
