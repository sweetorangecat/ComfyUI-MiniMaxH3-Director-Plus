# U11 媒体预览设计

## 目标

在不改变 U11 导演台现有分区、顺序、宽度、配色和工作流节点排版的前提下，为已经上传的图片提供缩略图预览，为已经上传的音色样本提供可播放的音频预览。

## 方案

- 上传流程保持不变：文件仍通过现有 `/h3-director-plus/upload` 接口进入 ComfyUI 输入目录，并将返回的相对文件名写入对应隐藏 widget。
- 预览使用上传完成后的 ComfyUI 服务端文件，而不是浏览器临时 `blob:` URL。图片和音频地址统一由已保存的 widget 文件名构造 `/view?filename=...&type=input`。
- 页面初次渲染、模式切换或重新打开工作流时，只要 widget 中已有文件名，就自动恢复对应预览。
- 图片预览位于所属上传槽内部、文件名和“选择文件”按钮下方。使用固定高度、`object-fit: contain` 的缩略图，不裁切素材；点击缩略图打开同源大图预览。
- 音频预览位于所属音色槽内部、文件名和“选择文件”按钮下方。使用浏览器原生 `<audio controls preload="metadata">`，提供播放、暂停、进度和音量控制，不自动播放。

## 布局约束

- 空上传槽保持当前高度，不预留空白预览区域。
- 有图片时，槽位纵向扩展并显示固定尺寸缩略图；两列网格仍按现有规则排列。
- 有音频时，播放器宽度不超过槽位，三列音色网格和移动端单列断点保持不变。
- 不新增画布节点，不移动 Settings、输出节点或导演台节点，不改变颜色 token 和区块标题。

## 状态与错误

- 上传开始时沿用现有 busy 状态；上传成功后立即更新文件名和预览。
- 图片加载失败时隐藏破损图片并显示简短中文状态“图片预览不可用”，文件本身仍保留，可继续生成。
- 音频加载失败时保留播放器并显示简短中文状态“音频预览不可用”，不静默清除上传值。
- 文件值为空时不渲染媒体元素，也不请求 `/view`。
- URL 参数必须使用 `URLSearchParams` 编码，兼容中文、空格和子目录文件名。

## H3 素材语义

- 图片预览只帮助确认槽位素材，不改变 `Picture 1` 至 `Picture 9` 的编号或首尾帧语义。
- 音频播放器只播放音色参考样本供人工确认；H3 原生音色参考仍只迁移音色与表达方式，不复用样本完整内容。
- 音色 1、2、3 与角色名称、`<Audio 1>`、`<Audio 2>`、`<Audio 3>` 的映射保持不变。

## 验收标准

- 上传图片后，同一槽位立即出现缩略图，图片 URL 指向对应 ComfyUI input 文件。
- 上传音频后，同一槽位立即出现可操作播放器，音频 URL 指向对应 ComfyUI input 文件。
- 从磁盘重新打开 U11 后，已有 widget 文件名能够恢复图片和音频预览。
- 模式切换导致上传槽重建后，预览仍根据 widget 值恢复。
- 空槽不显示预览；预览失败不丢失文件值。
- Director Plus 前端源代码测试、JavaScript 语法检查、完整 Python 测试和浏览器交互检查全部通过。
- U11 仍只有一个文件，且工作流结构校验保持 0 个可见节点重叠。
