# U11 AI VSR 质量优先重建设计

## 目标

在 U11 MiniMax H3 导演台中增加严格的“AI 细节重建”输出路径：H3 仍在低分辨率下生成以适配 3070 8G，VAE 解码后使用 DaSiWa 的 NVIDIA RTX VSR 逐帧重建，再流式编码为统一目标尺寸的 MP4。质量优先模式必须真实使用 RTX VSR，不能在依赖缺失时静默退回普通缩放。

## 当前状态与约束

- U11 当前由 `MiniMaxH3StreamingVideoCombine` 负责低显存流式输出。
- DaSiWa 已有 `DaSiWa_RTX_UpscalerRefiner`，支持 VSR、High Bitrate、质量档位和 CPU/磁盘输出，但它当前没有接入 U11 的最终输出路径。
- Windows 环境需要 `nvidia-vfx`/`nvvfx` 运行依赖，可能还需要 NVIDIA Broadcast SDK；ComfyUI 使用内嵌 Python，依赖必须安装到该 Python 环境。
- 3070 8G 的原生 H3 分辨率按时长自动降档；AI 放大必须逐帧或小块处理，禁止创建完整目标分辨率帧批次。

## 用户体验

导演台保留现有布局和中文设置面板，增加以下设置：

- `后处理模式`：`普通放大`、`AI 细节重建（RTX VSR）`。
- `AI 重建质量`：`High`、`Ultra`，默认 `High`；短视频可手动选择 `Ultra`。
- `AI 目标分辨率`：沿用导演台统一的目标分辨率，不在后处理节点重复定义尺寸。
- 质量优先模式下显示依赖状态：已安装可运行；缺失时在节点执行前给出中文错误和安装/验证命令。

普通放大仍可作为明确选择的兼容路径，但 AI 模式绝不自动降级。

## 数据流

```text
H3 原生低分辨率 latent
  -> VAE 解码
  -> 曝光/色彩保护
  -> AI VSR 逐帧或小块处理
  -> 目标尺寸对齐
  -> FFmpeg 流式写入 MP4
```

AI 重建节点只保留当前处理块在显存中，输出帧直接交给流式编码器；不得把整段 2K/4K 视频作为 `IMAGE` 批次留在 GPU。

## 3070 8G 策略

- 4 秒：原生约 1.0 MP，允许尝试 2K/4K AI VSR。
- 6 秒：原生约 0.65 MP，默认 2K，4K 允许但提示耗时。
- 8 秒及以上：默认 2K；选择 4K 时保持可运行，但提示“输出尺寸为 4K，细节受原生生成分辨率限制”。
- 自动按可用显存选择块大小，并在进入 VSR 前清理缓存；目标尺寸越大，优先缩小处理块而不是降低 AI 质量档位。
- 质量档位只控制 VSR 质量，不修改 H3 采样步数或提示词。

## 依赖与错误处理

执行 AI 模式时必须在实际运行环境中检查 `import nvvfx` 和 `VideoSuperRes`。检查失败时抛出可读错误，至少包含：

1. 当前使用的 ComfyUI 内嵌 Python 路径。
2. `ComfyUI-DaSiWa-Nodes/requirements.txt` 中的依赖安装命令。
3. Windows 可能需要安装 NVIDIA Broadcast SDK 的说明。
4. 重启 ComfyUI 后的验证命令。

错误必须在日志和节点状态中同时可见，不能输出一个实际使用普通插值却标记为 AI 的视频。

## API 兼容

`u11_api.json` 增加后处理字段，旧 API 不传时保持普通流式输出：

- `postprocess_mode`: `native` 或 `rtx_vsr`
- `rtx_quality`: `HIGH` 或 `ULTRA`

目标宽高仍由现有分辨率/画面比例输入生成，避免出现两个互相冲突的分辨率入口。

## 测试与验收

- 单元测试：AI 模式字段能传到输出节点；旧工作流默认仍为 `native`；质量值只允许 `HIGH`/`ULTRA`。
- 依赖测试：模拟 `nvvfx` 缺失时执行失败，并包含安装指导；依赖存在时才创建 VSR 实例。
- 显存策略测试：目标 4K 时使用块处理配置，不构造完整 4K GPU batch。
- 工作流校验：节点、连线、布局无重叠；U11 仍只有一个最终输出节点。
- 回归测试：现有测试全部通过，至少保持当前 235 个测试通过。
- 手工验收：用 3070 8G 生成 4 秒 2K AI VSR MP4，确认日志明确显示 RTX VSR；未安装依赖时确认不会生成伪 AI 输出。

## 非目标

- 本次不增加 Real-ESRGAN、扩散式视频超分或其他第三方模型。
- 本次不改变 H3 各模式的提示词、音色参考或原生采样逻辑。
- 本次不承诺从低分辨率视频恢复真实不存在的原始细节；VSR 只做受控的视觉增强和放大。
