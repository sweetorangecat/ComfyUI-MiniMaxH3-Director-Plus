# 导演台稳定视口设计

## 目标

避免 ComfyUI 重算节点或加载旧工作流时把导演台压缩成窄栏，并让生成规格、素材和后处理区域在默认视口中展示更多内容。

## 布局契约

- 导演台节点默认尺寸为 `1350×1760`。
- DOM 内容区可视高度为 `1280px`，纵向内容继续滚动。
- 内容区最小宽度为 `1180px`，超出容器时横向滚动，不通过压缩列宽破坏控件布局。
- 每次重绘只将小于默认尺寸的节点恢复到默认值；用户手动放大的宽高必须保留。
- 工作流生成器的导演控制台分组同步扩大，并保留四周间距。

## 验证

前端源码测试检查 CSS 最小宽度、横向滚动、默认高度和尺寸保留逻辑；工作流测试检查扩大后的导演分组仍包住节点；全量测试必须通过。
