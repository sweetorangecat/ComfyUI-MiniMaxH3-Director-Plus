# “文武双全”剧情试验：一手依据与原创候选

日期：2026-11-13。状态：文字研究与测试设计，未生成资产、未运行 GPU、未验收成片。作者配方及文件身份沿用[既有工作流核验](2026-11-13-wenwu-workflow-comparison.md)、[权重来源](2026-11-13-wenwu-author-assets.md)和[集成说明](../文武双全作者配方.md)，本文不重复下载研究。

## 一手资料能支持什么

- **自然表演的依据。** Kelly Reichardt 在 BFI 的直接访谈中谈到，让演员真正完成角色的工作，注意力便落在具体事情上；她也谈到给观众观察的时间。由此借鉴“人物一边处理事情、一边显露关系”，不复制《第一头牛》的情节或台词。这是创作方法，不是模型去塑料感的证明。[BFI 访谈，2021-05-25](https://www.bfi.org.uk/sight-and-sound/interviews/kelly-reichardt-first-cow)
- **动作可读性的依据。** 摄影师 Dan Laustsen 在 TheWrap 的直接问答中，说明《疾速追杀4》的目标之一是少移动摄影机、在演员动作时采用宽景。本文仅借鉴让人物位置和完整动作可见的原则，不借用枪战、危险特技或电影场面。[摄影师访谈，2023-03-25](https://www.thewrap.com/john-wick-chapter-4-cinematographer-dan-laustsen-interview/)
- **本次模型试验的依据。** 四只兔子的 Combat Base V2 发布简介明确涉及文戏身体动作、呼吸/声音动态与状态连续性；建议“动作 → 对白”，优先 No Trigger，强攻击或终结才考虑触发词。其效果数字属于作者自述，本次不采用为验收阈值。[原发布视频](https://www.bilibili.com/video/BV1rTbf6CEtj/)；[Bilibili 官方 API，已直接读取，作者 UID 49344623](https://api.bilibili.com/x/web-interface/view?bvid=BV1rTbf6CEtj)
- **执行表达的依据。** H3 官方 Ref 指南要求保持主体与说话者编号，按播放顺序描述动作/声音，在对应阶段声明音频职责；只参考音色时，不把样本原台词带入。它支持这些表达方式，不保证本场接触或长片成功。[官方指南，固定版本 d21241f](https://github.com/MiniMax-AI/MiniMax-H3/blob/d21241f0a4b3acbb34c97dae47fa417b7065e438/skills/h3-prompt-writing/references/ref-en.txt)

## 两个原创候选

**推荐《先松手》，24 秒。** 下班后的安静办公走廊。男同事想挽回一次失约，南宫婉准备结束争执；他情急抓住她的右腕，她先提醒，再以一次短步转腕脱开，最后仍答应明天把事情说清楚。冲突从“拦住人”转为“听人说话”，动作有情绪起因，也有克制的结尾。两位成年人、一只无字文件夹；南宫婉沿用已确认的现代通勤真人造型。平实侧窗光、哑光墙面，无群演、文字、镜面或水；无 BGM，保留衣料、脚步与接触声。第二人和文件夹的具体资产尚待执行端核实，不宣称已经存在或挂载。

**备选《归还》，24 秒。** 同事迟疑着把文件夹递回，又本能收回；南宫婉说“我不是来吵架的”，等他看向自己，再上前半步稳住夹子，直到对方松手，完整接回后道谢。它更突出听者反应、手指接触和道具所有权转换；双人共同持有薄物体容易遮挡手指，适合推荐场通过后另测，首轮不混入两种接触。

以上剧情、人物关系和对白均为本次原创提案；电影资料只提供导演方法的启发。

## 推荐场的时间与状态

| 时间 | 可见事件与对白 |
| --- | --- |
| 0–5 秒 | 中近景，南宫婉在画左、同事在画右。同事低声说“这次，算我欠你的。”她闭唇听完，视线从他脸上落到文件夹，轻呼气；不提前笑或接话。 |
| 5–9 秒 | 她抬眼：“欠不欠，明天再说。”说完闭唇，略向出口转身。保留近景可判断的皮肤、发际线和散发细节，避免美容广告式表演。 |
| 9–12 秒 | 切至同侧固定中全景，双手、腿脚可见。同事迈近半步，**右手**抓住她的**右腕**；抓握完成前没有“被抓住”的反应。 |
| 12–14 秒 | 她先看清接触，再看同事：“先松手。”这句说完后才开始脱离动作。 |
| 14–18 秒 | 她侧退半步、转动右腕并抽回右手；他的握持张开，前伸的身体随势向前半步后站稳。只有这一次脱离，无摔投、打击、受伤或重新抓握。 |
| 18–24 秒 | 两人完全分开，她看回他：“我会来。你也准时。”同事闭唇，肩膀松下，空右手放低；留出结果保持时间。 |

文件夹从首帧到结尾始终由她**左手**压在腹前，不换手、不交接、不凭空消失。左右手均指人物自身。几何尺寸、两人身高和夹子厚度是待资产核验的设计值，不能猜作已知事实；提交前先审同尺度比例图，并将审定数值写入实际模型提示词。以上为导演蓝图，不是完整 H3 可提交正文。

## 用短片区分剧情与长片问题

建议先编排两个独立 **15 秒**基准样片：文戏样片只演前两句与听者反应；动作样片从双方未接触开始，完整演“抓握 → 提醒 → 脱开 → 分离保持”。它们应各自写满时间线，不能从 24 秒成片裁切或加速来代替。短片通过后再测 24 秒整场，便于判断失败来自局部导演表达，还是跨窗的身份、动作与声音连续性；这种定位价值是测试设计推断，尚无实测支持。

两类短片及整场均可对照：A 为南宫婉使用同一已确认 WAV 的 **H3 原生音色参考**；B 为不输入参考音色、仍按同样台词生成声音。同事维持同一普通男声描述，两版的图像、台词、时间、配方和种子记录一致；无参考音色不等于静音。

验收同时看原速、关键帧和音轨：脸与发丝是否稳定、肤质是否自然；未说话者是否闭唇且先听后反应；接触是否发生在正确双手、分离是否干净；夹子是否一直归左手；后续窗口是否重演抓握或恢复旧状态。耗时、实际加载链和显存另按执行报告记录。引用资料、上传成功与运行完成均不能替代这些画面和声音判断。
