## 保留可对照的中间结果

新代码默认不额外保存数据，不改采样配方。需要诊断时，在启动 ComfyUI 的终端设置
`MINIMAX_H3_STAGE_DIAGNOSTICS=1`。Windows PowerShell：

```powershell
$env:MINIMAX_H3_STAGE_DIAGNOSTICS = "1"
```

随后由用户在同一终端使用原启动方式启动 ComfyUI。Linux 可在启动前使用
`export MINIMAX_H3_STAGE_DIAGNOSTICS=1`。诊断结束后取消变量，避免后续每次生成都写盘。

保持相同种子、提示词、输入、模型与采样设置，关闭人脸修复。节点自动在
`ComfyUI/output/h3_stage_diagnostics/<本次唯一编号>/` 保存：

- `first.latent`：首采完成的完整视频 latent。
- `upscaled.latent`：训练型放大完成、尚未二采的完整视频 latent。
- `second.latent`：二采完成的完整视频 latent。
- `manifest.json`：种子、阶段尺寸和部分二采参数，不保存提示词或音频。

三个文件可分别用 ComfyUI 的 LoadLatent、相同视频 VAE 解码、相同编码配置保存视频。
这是视频 latent，不含联合音频；比较画面即可。必须完整解码整段，抽取 latent 片段可能改变
VAE 时间上下文而引入误判。保存保持原 dtype，不做平滑、锐化或缩放。
会额外占用 CPU 内存和磁盘（随时长、尺寸增长）；写盘失败只记录警告，不中断生成。

若首采已有花纹，再对照底模、量化、加速 LoRA 与注意力实现；若仅放大后出现，检查放大器；
若只在二采出现，再固定其他条件比较分块边界与整帧路线。暂不自动关闭噪声、降低分辨率或
添加去闪烁滤镜，尚无证据证明这些操作可以解决本样本。

本地只有 8G RTX 3070；尚未完成本样本 32G 路线的 GPU A/B，不能宣称花纹已经修复。
