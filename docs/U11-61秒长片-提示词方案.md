# U11 61 秒长片提示词方案

这是新档位的规划与填写模板；目前未接入运行按钮，不能把全文直接粘进现有单段 U11 后就得到 61 秒视频。用户尚未提供剧情，下面的《归还钥匙》是独立演示，不代表用户作品。

## 怎么填写

填写一次全片设定，再填写 7 张段落卡。每张卡包含：全片时间、开场状态、分时动作、镜头、对白/画外音、现场声音、配乐、结束状态。用户看到 61 秒故事，底层根据显存决定是否继续拆短。

默认段长：0–9、9–18、18–27、27–36、36–45、45–54、54–61 秒。每段内部从 0 开始写净新增内容时间，不使用整片 27 秒等时间戳。续拍重叠与时码平移由执行器计算。

### 全片固定设定模板

- 故事：谁想完成什么，最后发生什么改变。
- 人物：稳定身份、发型、服装、可识别特征，不逐段换形容词。
- 场景：光线、天气、空间布局；运动方向与摄影轴线。
- 道具：外观、由谁持有、在哪只手、每段如何改变状态。
- 画面：画幅、景别范围、光色与质感。
- 声音：有无对白、说话人声线、现场声、是否有配乐。
- 输入：没有素材就是 T2VA；真实首帧才选 I2VA，人物设定图不能自动当首帧。

### 单段模板

Y–结束：动作结果、人物/道具状态、镜头运动如何延续或停稳。
对白及局部起止时间：无则明确无。
画外音：无则明确无。

## 完整示例：《归还钥匙》

目标：61 秒、24fps、16:9；同一书店内连续动作，无对白、无旁白、无配乐，用现场声验证跨段续接。七段均无新增图片/视频/音色上传，voice_mode=none。第一段语义为 T2VA，resolved_backend=fl2va_model；后续为该 Base 后端的 AV 续拍，不虚构新模式名。后处理目标为 1080p，2K 留待实测。人物与场景为文字设定，没有不存在的素材文件。

全片设定：一位黑色齐肩短发、穿深蓝针织开衫与米白长裤的年轻女店员，在即将开门的旧书店里把钥匙放回柜台。右手始终持一把无钥匙扣的黄铜钥匙，直至第六段放入柜台上的浅木托盘。左手起初自然下垂。书店右侧是高木书架，后方入口透入清晨柔光，柜台在画面左前方；光线稳定。摄影机位于店员左前侧，不越过行走轴线。她全程嘴唇自然闭合，无人声与歌唱。只保留脚步、衣料、门轴和钥匙落盘声。

### 第 1 段｜00:00–00:09｜建立行动

开场：店员站在关着的店门内侧，身体朝柜台方向，右手在腰侧握黄铜钥匙，左手空着。
- 0–2 秒：中全景固定，店员抬眼看向左前方柜台，右手握钥匙的位置不变；无对白/旁白。
- 2–6 秒：她迈步走向柜台，摄影机缓慢向后跟随，右侧书架产生平稳视差；鞋底轻触木地板。
- 6–9 秒：她继续同方向行走，柜台边缘进入左前景；相机保持速度，不停下来重新摆姿势。
结尾：身体仍朝柜台行进，右手钥匙在腰侧，左手轻微随步摆动。下一段从持续行走接入，不能再次从门口出发。

### 第 2 段｜00:09–00:18｜接近柜台

开场：店员已在书架与柜台之间，面朝左前方，正在行走；右手钥匙在腰侧。
- 0–3 秒：摄影机按原方向后移跟随；她自然走近柜台，视线落到台面浅木托盘。
- 3–6 秒：她减小步幅，身体转向柜台，右手仍未抬起；木地板脚步节奏减慢。
- 6–9 秒：她在柜台前站稳，左手轻触台边，右手仍握钥匙，视线移向柜台后方窗帘。
结尾：左手搭柜台边，右手持钥匙，身体正对柜台，头转向后窗。下一段直接执行左手离台转身，不重复走近。

### 第 3 段｜00:18–00:27｜注意到未开的窗帘

开场：店员面对柜台，左手搭台边，右手钥匙垂在腰侧，头看向柜台后窗。
- 0–3 秒：她确认窗帘仍合着，左手离开台边，躯干顺着视线转向窗户。
- 3–6 秒：摄影机小幅向侧面跟随，她沿柜台边走向窗帘拉绳；右手始终握钥匙。
- 6–9 秒：她停在拉绳旁，左手抬到胸前并握住拉绳，右手自然垂下。
结尾：左手握窗帘拉绳但尚未拉动，右手有钥匙；相机停为中景。下一段才拉窗帘，不提前改变光照。

### 第 4 段｜00:27–00:36｜打开窗帘

开场：店员站在后窗旁，左手握拉绳，右手钥匙垂下，窗帘仍合着。
- 0–3 秒：固定中景，她左手缓慢拉绳，窗帘开始向一侧打开，传来轻微滑轨声。
- 3–6 秒：窗帘继续打开，柔光渐渐落在柜台与店员肩部；曝光平稳变化，不闪白。
- 6–9 秒：她停止拉动，左手松开绳子，转头看回台面托盘；右手钥匙没有换手。
结尾：窗帘已打开，左手离绳，头转向柜台。下一段沿这次转向返回，不能再次打开窗帘。

### 第 5 段｜00:36–00:45｜回到托盘前

开场：窗帘打开，店员左手空着，右手握钥匙，身体正从窗户转向柜台。
- 0–3 秒：她转身回到柜台前，摄影机以小幅侧移维持中景，木托盘重新进入左下方画面。
- 3–6 秒：她站稳，视线落在托盘，右前臂缓慢抬起；左手轻搭台边。
- 6–9 秒：摄影机小幅靠近到中近景，右手把钥匙移至托盘上方，手指仍握紧钥匙。
结尾：黄铜钥匙悬在托盘正上方约一掌高度，尚未放下。下一段只完成落盘，不能重新举钥匙。

### 第 6 段｜00:45–00:54｜归还钥匙

开场：店员站在柜台前，右手钥匙在托盘上方，左手搭台边，视线朝下。
- 0–3 秒：镜头保持可见双手与托盘，她右手下移，钥匙接触木托盘，发出一次清晰的轻碰声。
- 3–6 秒：她松开手指，右手离开托盘，钥匙保持平躺在盘内；不再发出第二次落盘声。
- 6–9 秒：她抬眼看向店门，左手离开台边，双手均为空，肩膀开始朝门转动。
结尾：钥匙留在托盘，店员空手转向入口。下一段不能再让钥匙出现在手里。

### 第 7 段｜00:54–01:01｜走向开门

开场：店员站在柜台旁，双手为空，钥匙留在托盘，身体正在朝入口转动。
- 0–2 秒：摄影机缓慢后移成中全景，她朝入口走出两步，柜台与托盘留在前景。
- 2–5 秒：她接近门把手，左手伸向把手，右手空着自然下垂，脚步声靠近入口。
- 5–7 秒：左手握住把手并轻轻把门拉开一道缝，门轴发出轻声，外部环境声渐入；镜头在动作结果上收住。
结尾：门已有缝隙，左手握把手，右手空，柜台钥匙位置未变；不再启动新动作。

## 六个连接点

1→2：持续行走，同方向同相机速度，钥匙在右手。
2→3：站在柜台、左手搭台、头看后窗，下一段才离台。
3→4：左手握绳、窗帘未开，下一段才拉动。
4→5：帘已开、左手空、头回柜台，光照保持新状态。
5→6：钥匙悬在托盘上方，下一段才落盘。
6→7：钥匙已离手，空手转向店门，不重新取钥匙。

所有连接点默认按动作连续匹配；若真实输出不满足，重做该段或显式改为剪辑转场，不靠“保持一致”一句话掩盖。

## 有对白时怎么改

每段填写完整短句，并给出净内容局部起止时间，如“1.5–4.0 秒，店员说：钥匙我放在这里了。”台词原文保持不变。句末至少留出可读反应，段尾不开始新句。4–4.5 汉字/秒仅作普通说话速度的粗估，慢速或停顿需更长；超预算调整剧情段长或在自然句界拆段，禁止删字提速。

给实际发声者固定 (S1)、(S2)，每段重新注入声线基线；无样本不能称为克隆。FL2VA 长片续拍与 REF2VA 音色参考需分开验证，第一版不把带音色样本的 U11 自动路由强行塞进 Base 续拍。

## 执行稿与规划稿的区别

上面的中文卡片是可编辑导演稿。实现后的编译器只向每次采样发送该段的内容，加必要的全片约束，并把净内容时间映射为实际采样时间。Base 执行提示词使用官方三字段；中文台词保留原文，不把全片时间、文件路径或导演卡字段误当成模型新语法。没有隐藏翻译模型时，采用明确的中英模板或由用户提供经审阅的英文执行稿，不宣称能自动无损翻译任意中文长故事。
