# 独立视频超分：480p / 768p / 1080p

导入 `examples/H3-VideoFinish-480p-768p-1080p.json`。上传已生成的视频，不重新运行 H3。重启 ComfyUI 后可找到「H3 独立视频超分」节点。

- `resolution`：480p、768p、1080p，指短边。按输入比例输出偶数尺寸，不拉伸。例如16:9为1920×1080，H3的1344×768为1890×1080。
- `method=VOSR2`：按源帧和目标短边自动计算必要倍率，保留输入比例与已有较大尺寸。1344×768 到短边 1080 输出 1890×1080，约 1.40625 倍。TE 后端只接受整数 scale；小数倍率先用 float32 等比插值准备目标画布，再执行原生 1 倍 AI 重建，不先缩小源图、不跑 2 倍超分再缩回。默认保持 512 tile、1024 VAE tile、2 帧批次、wavelet，关闭时序缓存和编译。
- `method=SeedVR2`：复用项目现有适配，限定3B模型，避免自动选择7B。缺少节点或模型直接报错。
- `method=resize`：普通缩放基线，不宣称恢复细节。

默认读取49帧便于先比较耗时和画质；完整输出将加载视频的 `frame_load_cap` 改为0。保持 `force_rate=0`，输出帧率接自输入视频，音频直接连接输出，不经过扩散超分。超分帧数变化会报错。

新节点只处理已解码帧，可连接 H3 解码后的视频帧或独立加载的视频。原导演台现已接入同样的超分实现：选择智能画质、1080p FHD，再选择 VOSR2 或 SeedVR2，即可直接单采后超分，无需导入独立工作流。不要把H3二采、VOSR2、SeedVR2全部叠加。

依赖：VideoHelperSuite、当前ComfyUI的CreateVideo/SaveVideo；VOSR2使用 `tl2012tl/TE-Speed-VOSR2`（Windows Python3.12/3.13），模型目录 `models/vosr2/VOSR2/`；SeedVR2使用 `ComfyUI-SeedVR2_VideoUpscaler` 与 `models/SEEDVR2/` 下的3B及VAE权重。TE节点上游包含二进制扩展，跨平台不可假设兼容。

本地模型可复用，无需重复下载。未完成 5090 上完整视频的 GPU 画质/耗时对照，不能保证 VOSR2 比 SeedVR2 更快或更清楚。独立路线消除了重新跑 H3 的需要，但长片完整帧张量仍会占用 CPU 内存。后端返回 NaN/Inf、错误帧数或不足尺寸时直接报错，避免将坏帧保存成视频。
