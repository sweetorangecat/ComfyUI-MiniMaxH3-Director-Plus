# U11 清晰度增强版

本版本对应 ComfyUI 用户工作流：

`U11-MiniMaxH3-导演台Plus-中文增强版-AutoDL混合底模版-清晰度增强版.json`

## 路由

- 保持 U11 单一导演台与自动模式路由。
- 默认性能预设：`免费智能 1080p`。
- 默认后处理：`video_sr`。
- 20GB 级以上显存且依赖就绪时，自动使用 `quality_two_stage`：8 步首采、3D latent 放大、4 步低 sigma 二采。
- 2K/4K 请求先建立 latent 细节基准，再由 SeedVR2 完成最终尺寸重建。
- 低显存自动回退到兼容路线，不改变基础初采速度策略。

## 兼容性

增强版不新增或删除工作流节点，也不改变节点类型、连线和 U11 交互；它依赖仓库已有的 `trained_latent_fl`、`trained_latent_ref` 与 SeedVR2 路由实现。
